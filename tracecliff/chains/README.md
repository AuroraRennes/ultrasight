# chains/

Hand-written chain-mode stub assembly generated by `python3 -m tracecliff gen-chain N_TARGETS STUB_STRIDE`, not tracked in git, regenerated automatically by `make addr_chain`.

Each `chain_n<N>_s<S>.S` holds the `t0..t(N-1)` stub chain for one (`N_TARGETS`, `STUB_STRIDE`) pair swept by the Makefile, linked into `bench_addr.c`'s `-DCHAIN` build. Every stub does an `adr`+`br` to the next one except the last, which does a plain `ret`.
